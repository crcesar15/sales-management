## Executive Summary

Narrow web-controller exception handling to `InvalidArgumentException`, standardize status enum comparisons in touched controllers and API files, remove the dead `StockAdjustment` policy mapping from `AuthServiceProvider`, and remove dead `$request->validated()` calls from `Api\RoleController` and `Api\MeasurementUnitController`. This plan depends on Plan 01-04 because the API resource fixes must be in place before the broader controller pass, and on Plan 01-03 because service delete guards already throw `InvalidArgumentException`.
